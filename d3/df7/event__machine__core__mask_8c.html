Return the index of the next set bit in the core mask

Finds the next index in the core mask, starting after the index passed. Use with em_core_mask_first() to traverse a core mask, e.g.

int idx = em_core_mask_first(&mask); while (idx >= 0) { ... idx = em_core_mask_next(&mask, idx); }
